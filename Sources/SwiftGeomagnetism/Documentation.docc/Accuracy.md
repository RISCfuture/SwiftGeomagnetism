# Accuracy

How the calculation works, and how it's validated.

## Overview

### Calculation

The geodetic position is converted exactly to geocentric spherical coordinates on the WGS 84
ellipsoid. The spherical-harmonic expansion is summed there, and the result is rotated back into
the geodetic frame. The main field and its secular variation come from a single pass over the
coefficients.

Associated Legendre functions are generated by recurrences that never divide by the sine of the
colatitude. For orders above zero, the functions are carried divided by that sine, which is
exactly the form the east component needs. As a result, the geographic poles need no special
case, and the recurrences stay stable through degree 133.

Dates are converted to decimal years in UTC. The fraction is the elapsed share of the calendar
year, so leap years and the time of day both count.

### Validation

The test suite checks every result against independent reference values:

- **NOAA's published test values** for WMM2025 and WMMHR2025, plus the 100-point set distributed
  with the WMM2025 coefficient file. Results must match each value to within half a unit in its
  last printed digit. The 100-point file prints intensities to 10⁻⁶ nT, which is finer than its
  generator agrees with NOAA's own reference algorithm, so those columns allow 0.001 nT.
- **The British Geological Survey's web service**, an independent implementation of the WMM, at
  points NOAA's values don't cover: the geographic poles themselves, calendar dates, and heights
  of −1 km and 850 km.

### Model Uncertainty

Agreement with the reference values shows that this implementation evaluates the model
correctly. It says nothing about how well the model matches the real field. The World Magnetic
Model omits crustal anomalies, which WMMHR partly captures. It also omits magnetospheric and
ionospheric fields, so local declination can differ from the model by a degree or more. See the
[WMM2025 technical report](https://doi.org/10.25923/prbc-s316) for NOAA's error estimates.
